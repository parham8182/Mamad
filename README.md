# Telegram Number Guessing Bot 🎮

A Telegram bot written in Python using python-telegram-bot.

## Run locally

Set the environment variable BOT_TOKEN to your BotFather token, then run:

python main.py

## Commands

- /start
- /stats
- /top

## Deployment

The bot is designed to run as a long-running Telegram polling process. Do not put the bot token directly in the repository; use the hosting provider's environment variables.
